Stardew Helper는 스타듀밸리(Stardew Valley)를 더욱 쾌적하게 즐길 수 있도록 돕는 다목적 데스크톱 애플리케이션입니다. 번거로운 모드 관리부터 게임 내 실시간 정보 확인까지, 한 번에 해결하세요!

## ✨ 주요 기능

* **🎮 인게임 오버레이 지원**: 게임 플레이 중에도 단축키(`F3`)를 눌러 오버레이를 띄우고 각종 게임 정보를 바로 확인할 수 있습니다.
* **📦 모드(Mod) 추천 및 관리**: 유용한 추천 모드들을 소개하고, 바로 다운로드 페이지로 연결해 줍니다.
* **📊 실시간 게임 상태 트래킹**: 마지막 저장 시간 등 농장의 최신 상태를 대시보드에서 시각적으로 깔끔하게 확인하세요.
* **🎨 모던하고 아름다운 UI**: 스타듀밸리의 감성을 듬뿍 담은 세련된 인터페이스를 제공합니다.

* **🔄 원활한 자동 업데이트**: 앱 실행 시 백그라운드에서 최신 버전을 감지하고, 멋진 스플래시 화면과 함께 자동으로 설치 및 재시작합니다.
* **🚀 스마트 모드 업데이트**: 순차적 다운로드 대기열(Queue) 및 실시간 다운로드 진행률(%) 표시를 지원하는 스마트 매크로를 통해 모드를 안전하고 확실하게 자동 업데이트합니다.

## 📥 다운로드 및 설치

위 링크에 접속하거나 아래의 다이렉트 링크를 클릭하여 사용 환경에 맞는 파일을 바로 다운로드하세요.

1. **설치형 버전 (추천)**: [📥 Stardew Helper_1.2.7_x64-setup.exe 다운로드](https://github.com/2020KDG/Stardew_Helper_Releases/releases/download/1.2.7/Stardew.Helper_1.2.7_x64-setup.exe)

2. **무설치 버전 (Portable)**: [📥 StardewHelper_Portable.exe 다운로드](https://github.com/2020KDG/Stardew_Helper/releases/download/v1.2.7/StardewHelper_Portable.exe)
   - 설치 과정 없이 다운로드 후 바로 더블 클릭하여 사용할 수 있습니다.

3. **모드 설치를 권장합니다.** [📥 StardewHelperMod.zip 다운로드](https://github.com/2020KDG/Stardew_Helper/releases/download/v1.2.7/StardewHelperMod.zip)

## ⚠️ 필수 설치 프로그램

Stardew Helper를 정상적으로 실행하기 위해 아래 프로그램이 반드시 설치되어 있어야 합니다.

1. **Microsoft Edge WebView2 런타임** (필수)
   - Stardew Helper의 UI(웹 화면)를 띄워주기 위한 필수 시스템 프로그램입니다. 윈도우 11 및 최신 윈도우 10에는 기본으로 내장되어 있습니다.
   - 혹시 프로그램이 실행되지 않거나 하얀 화면만 나온다면 아래 링크에서 다운로드하여 설치해 주세요.
   - [📥 WebView2 런타임 다운로드 (Evergreen Bootstrapper)](https://developer.microsoft.com/ko-kr/microsoft-edge/webview2/)
   - *💡 꿀팁: 위에서 제공하는 `설치형 버전(setup.exe)`으로 설치하시면, 마법사가 알아서 WebView2 유무를 검사하고 없으면 자동으로 설치해 줍니다!*

2. **스타듀밸리 원본 게임 & SMAPI**
   - 게임 구동을 위한 필수 환경입니다. (SMAPI의 경우 Stardew Helper가 실행 시 설치 여부를 자동으로 감지하여 알려줍니다.)

## 🛠️ 개발 환경

이 프로젝트는 빠르고 가벼운 최신 데스크톱 앱 개발 프레임워크를 기반으로 만들어졌습니다.
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Backend / Desktop Binding**: [Tauri](https://tauri.app/), Rust
* **Game Hooking**: C# (SMAPI Mod)
